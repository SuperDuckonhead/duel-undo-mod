# 撤回版候选说明

新增独立 ygopro-undo.exe 和配套 WindBot-undo.exe，直接沿用原目录资源；新增独立配置，不覆盖原程序。

- 卡组编辑可撤回完整增删/拖动及排序、洗牌、清空操作。
- 对局可撤回自己的上次有效人工选择，支持连续撤回和改走新路线。
- 单人、AI、本机双开和朋友两人局域网单局共用重建与验证流程。
- 人工两人对战开放 Match：沿用原版比分、换备检查和下一局先后手流程；每小局独立撤回，不能回退已结束的小局或换备操作。恢复格式升级为 2，双方需一起更新；AI 仍为 Single。
- 朋友局每次撤回须对方同意；本机自由撤回显式开启并限回环接口。
- 恢复准备失败保留原局，双方恢复确认完成后继续；提交结果不明时暂停。
- AI 恢复其决策历史和内部状态；实际 62 行 AI 列表已完成宿主层连续撤回回归。
- 保留不检查卡组、不洗切卡组，录像仅记录最终保留分支。
- 普通双人局、本机双开和 AI 房间排除无关的 `single/` 练习脚本；单人练习保留场景快照，旧录像继续严格校验原资源。
- 联机握手升级为 v2：检查明确的消息/恢复格式和逻辑卡数据，取消双方整个 EXE、效果脚本全集和全部禁限表的等值要求；客机入房不扫描效果脚本，房主仍固定自身重建资源。
- 正常响应和计时复用原版处理方法；撤回同步期间才冻结普通界面，聊天沿用原通道，旧选择和计时确认仍受历史版本保护。
- 增加 `Uninstall-UndoMod.cmd` 卸载入口：确认清单后先备份再移除可验证的 mod 文件，默认保留配置、日志及原游戏资源。

当前是开发测试版，第二台电脑局域网及人工视觉验收尚未完成，不标正式发行。Tag、观战和 AI Match 暂未开放。构建提交和文件哈希以同包 build-manifest.json 及外部 release-files.json 为准；安装、卸载见 INSTALL.md。源码与固定第三方来源、许可文本随项目保存。近期修复和仍在排查的建房问题见 COMPATIBILITY.md；正式 Release 在完成验收后另行发布。
