# 更新日志

## v0.1.0-alpha.2 — 2026-09-12

Windows x64 测试版，发布本机已安装、两台电脑统一卡表后确认能够联机的 Match 候选包。仍为预发布，不代表完整验收已经结束。

### 本次更新

- 人工双人房支持 Single 和 Match。Match 沿用原版比分、换备及下一局先后手流程；每小局独立记录撤回历史，只能撤回当前未结束小局，不能撤回已结算比分或换备操作。
- 对局撤回支持 `Ctrl+Z`。朋友局逐次征得对方同意；AI 仍为 Single，本机自由撤回须显式开启并限回环接口。
- 普通响应、计时确认和对局流程复用原版处理；恢复期间才暂停普通输入。包括此前的计时确认、撤回同意/拒绝及窗口缩放修复。
- 撤回握手使用 v2，Match 恢复格式为 2。不再要求双方整个 EXE、全部效果脚本或全部禁限表相同；客机入房不扫描效果脚本，房主固定自身资源用于对局结算与撤回重建。
- 随包提供 `Uninstall-UndoMod.cmd`：确认后先备份，再移除清单内可验证的 mod 文件，默认保留原游戏资源、配置与日志。
- 继续支持编辑卡组撤回、单人练习、适配 WindBot、开局不检查卡组及不洗切卡组；录像只记录最终保留的操作分支。

### 联机实测与当前限制

2026-09-12，两台电脑使用相同 Match EXE，但第二台卡库比第一台多 28 张卡（15,077 对 15,049），共有卡片数值相同，仍在入房时被拒绝。统一卡表后，用户确认双方可以联机。

**本版仍比较完整逻辑卡表。** 多出未使用的新卡也会导致兼容失败。这是 mod 新增的限制，原版不要求完整卡表一致；取消这项要求已列入 [待更新功能](ROADMAP.md)，本版尚未实施。卡图、卡名和说明文本不参与该摘要；更新 mod 本身不会同步原游戏卡库。

双方需同时更新此 Match 包；alpha.1 和此前仅支持 Single 的旧包不能混用。同步卡库后须完全退出并重启游戏，不能只退房。卡库备份应放在游戏目录外，避免 `expansions` 中的备份 `.cdb` 被再次加载。

### 验证范围与已知问题

- 本机通过 Match 2:0、2:1、180 秒计时、当前小局撤回、换备与最终分支录像的自动化回归，安装、卸载和恢复验证通过，详见 [Match 测试](../tests/match-undo.md)及[交付记录](../tests/match-delivery.md)。
- 两台实际电脑联机成功由用户确认；双方轮流撤回、拒绝/超时、完整 Match 局间及视觉检查仍需分别验收。
- AI 首次启动等待、此前报告的建房网络错误及部分原生阻塞确认仍保留独立待验收项，见 [兼容及测试范围](COMPATIBILITY.md)。
- Tag、观战和 AI Match 暂不支持。
