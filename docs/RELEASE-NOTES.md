# 更新日志

## v0.1.0-alpha.3 — 2026-09-19

Windows x64 测试版，新增从卡组编辑器直接测试当前构筑的入口。本次编辑器测试流程已通过自动化回归和用户实测；仍为预发布，其他尚未完成的跨设备验收保持待测。

### 本次更新

- 普通卡组编辑页新增 **测试卡组**。直接上传当前未保存的主卡组、额外卡组及牌序，与悠悠王开始本机单局，无需先保存或重新读取卡组文件。
- 玩家固定先手，自动跳过准备、猜拳及先后手选择。使用 8000 LP、5 张起手、每回合抽 1 张、时间 0、不检查卡组、不洗切卡组；规则沿用当前 AI 规则，AI 页关闭时也能正常启动。
- 允许通常构筑数量之外的测试，主卡组与额外卡组合计上限为 250 张。副卡组不投入对战，保留在原编辑会话中。
- 准备期间可取消。对局结束或投降并处理录像提示后，返回原编辑会话，恢复构筑、牌序、副卡组、名称、查卡状态、未保存标记和撤回历史；再次编辑后测试使用最新内容。
- 准备失败、断开及检测到引擎或机器人致命失败时恢复编辑器并给出错误。测试资源使用已加载数据的独立快照；测试本身不保存卡组，不修改普通房间偏好，并清理本次会话拥有的连接和机器人。
- 保留已有编辑撤回、对局撤回、人工 Single/Match、AI Single 及随包卸载工具。

### 验证范围与当前限制

- 24 项原生测试、8 项真实测试会话和编辑器回归通过。覆盖未保存牌序、非标准数量、失败后重试、连续编辑后再测试、录像提示期间取消、引擎及机器人故障恢复，以及文件、偏好和撤回历史隔离。
- 用户已完成本次编辑器测试流程实测并确认通过。开发验证记录和复跑命令随源码提供。
- 当前测试只使用实际投入的卡；全卡池编辑模式、试加新卡及赛后选卡加入仍待后续实现。
- 机器人空闲时被外部终止，要到下一次对局通信才会检测到。
- 联机仍要求双方实际加载的完整逻辑卡表相同；更新 mod 不会同步原游戏卡库。跨电脑的完整撤回、Match 局间及视觉验收仍按既有状态保留，详见 [兼容及测试范围](COMPATIBILITY.md)。Tag、观战和 AI Match 暂不支持。

### 下载、安装与来源

- [安装包与发布说明](https://github.com/SuperDuckonhead/duel-undo-mod/releases/tag/v0.1.0-alpha.3)
- 文件名：`ygopro-undo-v0.1.0-alpha.3-win-x64.zip`。
- 准确构建源码及产物哈希见包内 `undo-mod/build-manifest.json`；ZIP 校验值见 Release 随附校验文件。

本包为增量安装包，需要已有完整 YGOPro、WindBot 资源及 .NET Framework 4.8，不包含原游戏卡库、卡图、效果脚本或私人卡组。关闭撤回版和配套 AI 后解压到原游戏根目录，保留原程序与资源。安装、测试卡组和卸载步骤见 [INSTALL.md](INSTALL.md)。

## v0.1.0-alpha.2 — 2026-09-12

Windows x64 测试版，发布本机已安装、两台电脑统一卡表后确认能够联机的 Match 候选包。仍为预发布，不代表完整验收已经结束。

### 本次更新

- 人工双人房支持 Single 和 Match。Match 沿用原版比分、换备及下一局先后手流程；每小局独立记录撤回历史，只能撤回当前未结束小局，不能撤回已结算比分或换备操作。
- 对局撤回支持 `Ctrl+Z`。朋友局逐次征得对方同意；AI 仍为 Single，本机自由撤回须显式开启并限回环接口。
- 普通响应、计时确认和对局流程复用原版处理；恢复期间才暂停普通输入。包括此前的计时确认、撤回同意/拒绝及窗口缩放修复。
- 撤回握手使用 v2，Match 恢复格式为 2。不再要求双方整个 EXE、全部效果脚本或全部禁限表相同；客机入房不扫描效果脚本，房主固定自身资源用于对局结算与撤回重建。
- 随包提供 `Uninstall-UndoMod.cmd`：确认后先备份，再移除清单内可验证的 mod 文件，默认保留原游戏资源、配置与日志。
- 继续支持编辑卡组撤回、单人练习、适配 WindBot、开局不检查卡组及不洗切卡组；录像只记录最终保留的操作分支。

### 联机实测与当前限制

2026-09-12，两台电脑使用相同 Match EXE，但第二台卡库比第一台多 28 张卡（15,077 对 15,049），共有卡片数值相同，仍在入房时被拒绝。统一卡表后，用户确认双方可以联机。

**本版仍比较完整逻辑卡表。** 多出未使用的新卡也会导致兼容失败。这是 mod 新增的限制，原版不要求完整卡表一致；取消这项要求已列入 [待更新功能](ROADMAP.md)，本版尚未实施。卡图、卡名和说明文本不参与该摘要；更新 mod 本身不会同步原游戏卡库。

双方需同时更新此 Match 包；alpha.1 和此前仅支持 Single 的旧包不能混用。同步卡库后须完全退出并重启游戏，不能只退房。卡库备份应放在游戏目录外，避免 `expansions` 中的备份 `.cdb` 被再次加载。

### 验证范围与已知问题

- 本机通过 Match 2:0、2:1、180 秒计时、当前小局撤回、换备与最终分支录像的自动化回归，安装、卸载和恢复验证通过，详见 [Match 测试](../tests/match-undo.md)及[交付记录](../tests/match-delivery.md)。
- 两台实际电脑联机成功由用户确认；双方轮流撤回、拒绝/超时、完整 Match 局间及视觉检查仍需分别验收。
- AI 首次启动等待、此前报告的建房网络错误及部分原生阻塞确认仍保留独立待验收项，见 [兼容及测试范围](COMPATIBILITY.md)。
- Tag、观战和 AI Match 暂不支持。
