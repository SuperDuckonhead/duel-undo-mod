# 撤回版候选说明

新增独立 ygopro-undo.exe 和配套 WindBot-undo.exe，直接沿用原目录资源；新增独立配置，不覆盖原程序。

- 卡组编辑可撤回完整增删/拖动及排序、洗牌、清空操作。
- 对局可撤回自己的上次有效人工选择，支持连续撤回和改走新路线。
- 单人、AI、本机双开和朋友两人局域网单局共用重建与验证流程。
- 朋友局每次撤回须对方同意；本机自由撤回显式开启并限回环接口。
- 恢复准备失败保留原局，双方恢复确认完成后继续；提交结果不明时暂停。
- AI 恢复其决策历史和内部状态；实际 62 行 AI 列表已完成宿主层连续撤回回归。
- 保留不检查卡组、不洗切卡组，录像仅记录最终保留分支。
- 普通双人局、本机双开和 AI 房间排除无关的 `single/` 练习脚本；单人练习保留场景快照，旧录像继续严格校验原资源。
- 增加 `Uninstall-UndoMod.cmd` 卸载入口：确认清单后先备份再移除可验证的 mod 文件，默认保留配置、日志及原游戏资源。

当前是开发测试版，第二台电脑局域网及人工视觉验收尚未完成，不标正式发行。Match、Tag、观战暂未开放。构建提交和文件哈希以同包 build-manifest.json 及外部 release-files.json 为准；安装、卸载见 INSTALL.md。源码与固定第三方来源、许可文本随项目保存。近期修复和仍在排查的建房问题见 COMPATIBILITY.md；正式 Release 在完成验收后另行发布。
