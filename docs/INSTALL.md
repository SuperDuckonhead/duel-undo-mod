# 安装与使用

这是沿用原游戏资源的独立撤回版。将候选 ZIP 解压到原 ygopro.exe 所在目录，再启动 ygopro-undo.exe。WindBot-undo.exe 由客户端自动启动。

新增程序文件只有：

- ygopro-undo.exe
- WindBot/WindBot-undo.exe
- WindBot/WindBot-undo.exe.config
- WindBot/undo-deps/x86/sqlite3.dll
- WindBot/undo-deps/x64/sqlite3.dll

undo-mod 目录附带说明、许可文本和构建清单。原 pics、deck、script、expansions、pack、cards.cdb、字体/材质/音效，以及 WindBot 的 Decks、Dialogs、bots.json、原配置继续从原位置读取，无需复制。保留原 ygopro.exe、Bot.exe、WindBot.exe 及原 DLL；不要改名覆盖它们。如果同名新增文件已存在，先核对旧 mod 清单和哈希，避免覆盖来历不明的文件。

新版设置写入 system-undo.conf；首次读取原配置作为默认值，原 system.conf 不改写。两个新版实例保存时会协调写入。正常编辑并主动保存卡组仍会修改共享的卡组文件。

## 撤回

卡组编辑页用“撤回”或 Ctrl+Z，返回上一次完整增删、拖动、排序、洗牌或清空操作。文本框内的 Ctrl+Z 不触发卡组撤回。保存后仍可撤回，但不会自动写盘；切换卡组开启新的编辑历史。

单人练习、AI 和支持撤回的双人对局可使用“撤回选择”或 Ctrl+Z。焦点在聊天等文本框时不触发对局撤回，按住快捷键不会连续撤回。目标是自己最近一次已被内核接受的人工选择；后续双方操作一起回退。自动跳过不会单独成为人工撤回点。成功后可以再次撤回，也可以选择另一条路线。

本地双开：建房时勾选“仅本机自由撤回”，仅接受本机连接，无需另一端逐次确认。未勾选时使用双方确认流程。AI 对局无需 AI 同意，但 AI 也必须完成恢复，才重新开放出牌。

朋友局域网：双方使用相同候选构建和兼容决斗资源，房主不勾本机开关，朋友输入房主的局域网 IPv4 地址和端口加入。每次请求显示公开的目标步骤，对方同意后恢复；拒绝或 30 秒内未同意则取消。两端确认完成后才可继续出牌。

建房和 AI 页面保留“不检查卡组”“不洗切卡组”，可分别或同时启用；本局撤回沿用开局设置。首版只开放两人单局，Match、Tag 和观战有明确拒绝提示。

恢复失败但尚未提交时保留原局；若提交结果不确定，房间会暂停，此时结束该局重新开局。对局结束后的录像只保存最终保留分支。撤回不能消除玩家已经看到的信息，因此适用于练习及朋友约定的对局。

## 卸载

关闭新版客户端及其 AI。按随包构建清单逐项删除上述五个程序文件和本次新增的 undo-mod 文档/许可/构建清单。不要递归删除 WindBot 或共享资源目录。system-undo.conf 和 undo-logs 可自愿保留或另行删除；卡组、原配置和原程序保留。之后继续启动原 ygopro.exe。

## 两台电脑候选验收

先在两台电脑安装同一个候选包，各自使用完整的原游戏资源。为避免卡组保存影响常用卡组，另存一份测试卡组。保持候选版本一致；若资源兼容检查失败，记录两端提示并核对数据库和逻辑脚本，不要跳过检查。

1. 房主建立“两人单局”，不勾“仅本机自由撤回”。记下端口；另一台输入房主局域网 IPv4 地址加入。如果 Windows 弹出防火墙提示，仅允许当前可信的专用网络。
2. 房主在建房前设置“不检查卡组”和“不洗切卡组”，双方核对房间显示的开局设置。开局后记下双方手牌数量、生命值、回合/阶段、场上卡与剩余时间。各完成至少一次人工操作，让后手也有有效选择。
3. 玩家 A 发起撤回，玩家 B 先拒绝。确认两端原局和时间恢复，都能继续操作。再发起一次并等待超过 30 秒，确认取消。
4. 再次发起并由对方同意：双方应回到 A 最近一次有效人工选择之前。核对各自视角，另一方的隐藏手牌/盖牌身份不能额外显示；两边均完成恢复后才重新出牌。
5. 交换发起者，连续撤回两次，再选择不同操作继续至少一个回合。记录原路线与新路线。结束并保存录像，回放应只包含最终保留路线。
6. 使用测试对局观察恢复过程中的窗口、卡牌位置、选项和文字；切换到卡组编辑页做添加、删除、撤回，确认历史与对局分开。最后分别启动原版与新版，确认原版仍可用。

每次记录两端候选构建号、系统版本、资源兼容提示、操作顺序、预期与实际结果。失败时保留双方日志及异常画面、停留在当前状态，并记录是否处于“等待同意”“正在恢复”或“等待双方确认恢复”。第二台设备尚未执行这些步骤时，验收结果保持待测。
