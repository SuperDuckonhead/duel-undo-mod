# 待更新功能

`v0.1.0-alpha.3` 已发布编辑器直接测试当前卡组的能力。以下记录仍待实现的功能，以及卡组测试后续阶段的边界。

## 简化联机检查

状态：待实现。

当前问题：客户端版本相同、共有卡片数值相同，仅一端新增 28 张卡也会拒绝入房。原版没有完整卡表等值检查；当前 mod 的额外限制需要收窄。

计划：

- 沿用原版通信版本、房间密码、席位/准备状态，以及房主按房间规则和所选禁限表检查提交卡组的流程。
- 保留双方是否支持撤回、撤回消息格式及 Match 恢复格式等必要兼容检查。
- 取消整个逻辑卡表必须相同的要求；不恢复整个 EXE、效果脚本全集或全部禁限表的比较。
- 对实际对局和选卡交互需要的数据按需处理。实施时核查宣言卡牌等依赖本地卡库的选择，保证房主结算与双方选择含义一致；缺失必要数据时给出具体提示。
- 将“版本不兼容”“必要卡片数据缺失”和“握手异常”等原因分开提示，便于直接定位。

验收方向：同一撤回版本、仅未使用卡片集合不同可以入房；不兼容的撤回格式仍明确拒绝；房主未知卡、宣言卡牌及特殊生成卡的处理正确；Single、Match、计时和撤回恢复流程保持可用。

## 卡组测试功能

状态：编辑器直接开局已于 `v0.1.0-alpha.3` 实装；全卡池相关阶段待实现。

已实现：普通卡组编辑页点击“测试卡组”，直接使用当前未保存的主卡组、额外卡组和牌序，与悠悠王开始玩家固定先手的本机单局；准备期间可取消，结束或失败后恢复原编辑内容及撤回历史。无需写盘，也不改变普通房间偏好。操作说明见 [INSTALL.md](INSTALL.md#测试当前卡组)。

后续计划：

- 全卡池编辑模式开关，以及该模式下的卡片访问规则。
- 测试中试加当前构筑以外的新卡。
- 测试结束后选择新卡加入编辑中的卡组。

当前已交付阶段只测试实际投入的卡；不代表上述后续功能已经实现。
