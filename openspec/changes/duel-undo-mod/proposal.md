## Why

在卡组编辑时误加、误删卡牌，以及练习展开、与 AI 对战或朋友联机时选错目标、误点发动，都需要能够回到操作之前重新尝试。为当前 YGOPro 安装包增加卡组编辑撤回和可继续对战的撤回能力，并直接在原目录安装使用，避免重复下载卡图、卡组与脚本。

## What Changes

- 提供单独启动的 `ygopro-undo.exe` 和适配的 `WindBot-undo.exe`，支持单机练习、AI 对战、本地双开和朋友局域网对战。
- 在卡组编辑页面加入撤回按钮及不抢占文本输入的 Ctrl+Z；撤销最近一次卡牌加入或删除，恢复主卡组、额外卡组、副卡组的内容和顺序，支持连续撤回。
- 编辑撤回按完整用户操作记录，使用独立于对局的本地历史；恢复的是当前编辑内容，只有玩家主动保存才写入原卡组文件，切换卡组不沿用上一副卡组的历史。
- 保留原卡组编辑器，以及 AI 开局和普通建房界面的“不检查卡组”“不洗切卡组”设置；对战重建保留开局设置，不额外洗牌。
- 撤回到发起者最近一次有效提交选择之前；其后双方操作和自动结算一并撤销，支持在当前对局内连续撤回并重新选择。
- 朋友局域网对战要求双方使用兼容的撤回版，由建房端协调，每次撤回都取得对方明确同意。
- 单机及 AI 对战直接发起回退；本地双开提供仅限本机参与者的自由撤回房间设置。
- 重建决斗状态并同步客户端；AI 对战还恢复 WindBot 的决策状态与随机状态。重建失败保留当前对局，恢复同步未完成时不允许继续出牌。
- 新增程序直接安装到当前 YGOPro 目录，复用 `pics/`、`deck/`、`script/`、`expansions/`、`cards.cdb`、字体、音效及 WindBot 数据；新版配置另存，原版与新版可以并存。
- 用源码仓库管理修改后的源码、依赖版本、构建脚本、配置模板和文档；GitHub Release 提供仅含新增程序、必要依赖及安装说明的增量 ZIP。
- 对战撤回的首版边界为正在进行的双人对局；编辑撤回作用于当前打开的普通卡组编辑会话。公共服务器支持、TAG 多人对战、赛后复活、对战间换备页面、恢复已删除卡组文件以及重做已撤销操作不属于本次计划。

## Capabilities

### New Capabilities

- `duel-undo`: 卡组编辑及对局选择的历史与撤回、原编辑和开局选项兼容、联机同意和同步、AI 状态恢复、同目录资源复用，以及可追溯的增量发行包。

### Modified Capabilities

无。当前 `openspec/specs/` 没有现存业务规格。

## Impact

- 当前目录是 YGOPro 1.036.2 运行包，无 Git 仓库、C++ 客户端或决斗内核源码；已包含 WindBot 程序、AI 数据及 .NET Framework 4.8 配置。源码基线匹配和原样构建是实施前置任务。
- 预计改动匹配源码中的卡组编辑事件与状态、对局宿主、单人模式、响应记录、客户端消息/UI、资源与配置定位、WindBot 消息处理和决策执行路径；对战撤回涉及客户端与建房端的协议扩展，编辑撤回仅在本机处理。
- 引擎采用初始条件与操作历史重建的候选方案，必须先验证固定引擎、数据库和脚本下的确定性；现有录像后退代码是参考，不代表已经支持实战撤回。
- 开发源码与运行资源分开管理；不将整个游戏安装目录纳入 Git，不覆盖原客户端、原 WindBot 或原资源文件。发行构建保留对应源码、版本记录及上游许可信息。
