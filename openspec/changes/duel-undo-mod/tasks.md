## 3. 有效响应历史与撤回目标

- [ ] 3.1 定义并记录含不检查/不洗切设置的初始会话、有效响应、撤回点、计时和会话/历史版本，在宿主与单人模式共用；验收为固定输入产生可核对的顺序号、玩家、提示摘要、响应及初始条件记录。
- [ ] 3.2 从 UI 到宿主传递人工/自动选择来源，并在引擎接受后提交有效响应；验收为人工选择产生撤回点，自动跳过仍能重放，未提交勾选和 MSG_RETRY 无效响应不增加撤回点。
- [ ] 3.3 实现按发起者查找最近有效撤回点及批准时的目标固定；验收为双方交错操作中总是选中发起者自己的正确目标，另一方后续行动被纳入撤销范围。
- [ ] 3.4 实现成功提交后的历史截断和新分支记录；验收为连续撤回逐步前进到更早选择，新选择不会恢复旧分支，失败不改变原历史。
- [ ] 3.5 将正常录像记录与当前有效分支保持一致；验收为撤回后换路线、结束并保存的录像能够重放新路线，不包含旧分支响应或重复聊天。
