# 有计时对局与撤回确认修复（2026-09-11）

## 问题与修复范围

180 秒的本机双开对局在正常召唤后出现无法继续操作、计时继续减少的情况，复现前没有撤回。0 秒对照局能完成发动、连锁响应和结算。宿主发送顺序为 `STOC_TIME_LIMIT(new prompt)`、选择消息、边界状态；原客户端只在选择消息处更新 prompt，计时确认因此携带旧编号，被客户端队列或宿主丢弃。

修复在收到计时包时发布该包的 prompt，同时保持普通输入暂停，直到原有边界状态允许提交。计时确认继续走原处理器和传输队列；旧会话、旧历史、事务和关闭保护保留。

撤回协商期间原输入门会吞掉鼠标事件。同意/拒绝现在仅将命中可见按钮的完整鼠标手势交给原生按钮处理，不改变原游戏控件的焦点。按钮随窗口缩放，避免与撤回入口重叠。按下时绑定界面已显示的事务；抬起和排队提交继续校验同一事务。目标键和提示文字在同一锁中读取，避免后台请求先于画面更新造成误批准。
