# YGOPro 撤回版

独立启动的 Windows 修改版客户端和配套 WindBot，直接使用原 YGOPro 目录资源。

支持卡组编辑撤回，以及单人练习、AI、本机双开、双方兼容客户端的局域网两人单局撤回。朋友局逐次确认；首版不含 Match、Tag 和观战。当前为本地候选，第二台电脑和人工视觉验收待完成。
